# tela2

Servidor simples do overlay **Assistindo Agora**.

## Render

Use exatamente:

```text
Build Command: npm start
Start Command: npm install
```

O projeto foi preparado especificamente para esses dois comandos.

## Comandos no chat

```text
!tf Nome do filme 2024
!ts Nome da série 2024
```

## Rotas

```text
/
 /ping
 /health
 /state
 /events
```

`/` e `/ping` respondem `OK`.
