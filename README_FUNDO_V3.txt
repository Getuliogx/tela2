TELA2 - Fundo personalizado V3

1) Atualize o projeto do Render com esta pasta tela2-main.
2) No StreamElements, substitua os 5 campos do Custom Widget pelos arquivos do ZIP F_WIDGET_FUNDO_PAINEL_V19.zip.
3) O painel /admin passa a controlar o fundo do quadrinho.

O painel envia themeConfig no /state.
O widget V19 lê themeConfig e aplica o fundo imediatamente.

Automático:
- usa título, descrição, gêneros e palavras-chave do TMDB;
- possui combinações específicas para Coraline, Rebelde, True Blood, Shrek, Mad Max, Kung Fu Panda, Midsommar e A Substância;
- outros títulos usam os metadados para escolher elementos.

Manual:
- escolha elementos visuais (botões, mansão, gatinho, lua, escola, música, estrelas, coração, flores, sangue, bambu, estrada, fogo, deserto, magia, laboratório, células, floresta, castelo, cidade, chuva, mar);
- escolha estilo e duas cores;
- clique Aplicar fundo agora.
